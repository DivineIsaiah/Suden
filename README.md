# SUDEN

SUDEN is a subscription-based educational technology platform designed to provide structured, accessible, and practical online learning.

The project is being developed as a full-stack software engineering project, progressing from a static frontend prototype into a production-oriented web application.

## Project Status

**Current phase:** Frontend foundation

**Current stack:**

* HTML5
* CSS3
* JavaScript

**Planned stack:**

* React
* Java
* Spring Boot
* PostgreSQL
* Docker
* AWS
* CI/CD

## Vision

SUDEN aims to provide a complete learning platform with separate experiences for:

* Students
* Instructors
* Administrators

The platform is intended to support course discovery, enrollment, learning, progress tracking, certificates, course management, instructor analytics, administration, and eventually subscription-based access.

## Development Philosophy

SUDEN is being developed incrementally.

Each major milestone should result in a working improvement to the application rather than simply adding files or technologies.

The development process follows:

**Learn → Apply → Practice → Break → Debug → Fix → Document**

Technical decisions, architectural changes, and significant milestones will be documented as the project evolves.
